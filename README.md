# 🍥 Naruto Blog

Aplicación web que consume la API de Naruto para explorar personajes del universo ninja. 
Permite navegar por categorías, ver detalles de cada personaje y guardarlos en favoritos.

## 🚀 Demo en vivo

[Ver aplicación](https://naruto-blog.netlify.app/)

## 🛠️ Stack

- React
- JavaScript
- CSS
- Vite
- Context API (gestión de estado)
- Netlify (deploy)

## ✨ Funcionalidades

- Consumo de API externa de Naruto
- Listado de personajes por categorías (Ninjas, Akatsuki, Bestias)
- Vista detalle de cada personaje
- Sistema de favoritos
- Navegación multi-página con menú lateral
- Diseño responsive temático
